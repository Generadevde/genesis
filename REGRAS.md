# Regras do projeto Genesis

Estas regras valem para todo o trabalho neste repositório, em qualquer conversa.

1. **Ordem, certo por certo.** Uma coisa de cada vez. Só se passa para o próximo passo quando o atual estiver certo e aprovado pelo dono do projeto.
2. **Na dúvida, perguntar.** Se algo estiver ambíguo ou mal definido, pergunta-se antes de fazer. Nada de suposição.
3. **Nenhum número inventado.** Valores, limites, tamanhos, quantidades e taxas vêm do dono do projeto. Onde faltar um número, o trabalho para e a pergunta é feita.
4. **As decisões são do dono do projeto.** Opções podem ser apresentadas; a escolha é dele.
5. **Tudo documentado, código explicado.** Cada sistema tem seu documento em `docs/`. O código tem comentários dizendo o que faz e por quê.

## Inspiração
